Architecture Web

URL — Anatomie

Une URL (Uniform Resource Locator) identifie de manière unique une ressource sur le web. Elle se décompose en plusieurs parties :

URL
https://www.monsite.fr:443/dossier/page.php?id=5&cat=info

 │ protocole │   domaine    │port│   chemin   │   paramètres GET  │
PartieValeurDescription
Protocolehttps://HTTP sécurisé (SSL/TLS)
Domainewww.monsite.frNom de domaine du serveur
Port:443443 = HTTPS, 80 = HTTP (optionnel si standard)
Chemin/dossier/page.phpEmplacement du fichier
Query string?id=5&cat=infoParamètres GET

Protocole HTTP — Requête / Réponse

HTTP (HyperText Transfer Protocol) est le protocole de communication entre le client (navigateur) et le serveur. C'est un protocole sans état (stateless).

Requête HTTP

HTTP
GET /page.php?id=1 HTTP/1.1
Host: monsite.fr
Accept: text/html
Cookie: session_id=abc123

Réponse HTTP

HTTP
HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Set-Cookie: session_id=abc123

<html>...</html>

Codes de statut HTTP

2xx — Succès : 200 OK (réponse normale), 201 Created (ressource créée)

3xx — Redirection : 301 Moved Permanently, 302 Found (redirect temporaire)

4xx — Erreur client : 400 Bad Request, 403 Forbidden, 404 Not Found

5xx — Erreur serveur : 500 Internal Server Error, 503 Service Unavailable

Architecture Client-Serveur

Architecture
┌──────────────┐   Requête HTTP GET/POST    ┌──────────────────┐ 
 │   NAVIGATEUR │  ─────────────────────── ▶ │   SERVEUR WEB    │ 
 │   (Client)   │                            │  (Apache/Nginx)  │ 
 │              │ ◀ ───────────────────────  │       ↕          │ 
 │  HTML rendu  │   Réponse HTML/CSS/JS      │  Interpréteur PHP│ 
 └──────────────┘                            │       ↕          │ 
                                            │  Base de données │ 
                                            └──────────────────┘
ℹ️
PHP s'exécute côté serveur. Le client ne voit jamais le code PHP, uniquement le HTML généré. C'est la différence fondamentale avec JavaScript qui s'exécute côté client.

Boucles

PHP
<?php
// ── for : quand on connaît le nombre d'itérations ──
for ( $i = 0 ; $i < 5 ; $i++ ) {
    echo $i . " " ;  // 0 1 2 3 4
}

// ── while : tant qu'une condition est vraie ──
$compteur = 0 ;
while ( $compteur < 3 ) {
    echo $compteur ;
    $compteur++ ;   // ne pas oublier l'incrémentation !
}

// ── do...while : s'exécute AU MOINS une fois ──
do {
    echo "Exécuté" ;
    $compteur++ ;
} while ( $compteur < 3 );

// ── foreach : parcours de tableaux ──
$fruits = [ "pomme" , "banane" , "cerise" ];
foreach ( $fruits as $fruit ) {
    echo $fruit ;
}

// foreach avec clé => valeur
$personne = [ "nom" => "Alice" , "age" => 20 ];
foreach ( $personne as $cle => $valeur ) {
    echo "$cle : $valeur" ;
}

// break et continue
for ( $i = 0 ; $i < 10 ; $i++ ) {
    if ( $i == 3 ) continue ; // saute le 3
    if ( $i == 6 ) break ;    // arrête à 6
}
?>

📤 Méthode GET : Données visibles dans l'URL, limité ~2000 caractères, peut être mis en favori/partagé. Idéal pour : recherche, filtres, pagination. Ne pas utiliser pour données sensibles.

📬 Méthode POST : Données dans le corps de la requête, pas de limite de taille notable, non mémorisé dans l'URL. Idéal pour : connexion, inscription, paiement. À utiliser pour données sensibles.

⚠️
Sécurité : Ne JAMAIS utiliser directement les données utilisateur dans du SQL ou du HTML. Toujours utiliser htmlspecialchars() pour l'affichage et les requêtes préparées pour la base de données.

Sessions & Cookies

Sessions

Une session permet de stocker des informations côté serveur, identifiées par un ID unique (PHPSESSID) stocké dans un cookie côté client.

PHP
<?php
// Démarrer la session (à placer tout en haut du script)
session_start ();

// Stocker une variable de session
$_SESSION [ "utilisateur" ] = "Alice" ;
$_SESSION [ "role" ] = "admin" ;

// Accéder à une variable de session
echo "Bonjour " . $_SESSION [ "utilisateur" ];

// Vérifier si une variable de session existe
if ( isset ( $_SESSION [ "role" ])) {
    echo "Votre rôle est : " . $_SESSION [ "role" ];
}

// Supprimer une variable de session
unset ( $_SESSION [ "role" ]);

// Détruire toute la session
session_destroy ();
?>

Cookies

Un cookie est un petit fichier texte stocké côté client (navigateur) par le serveur. Il permet de conserver des informations entre les requêtes.

PHP
<?php
// Définir un cookie (nom, valeur, expiration, chemin, domaine, sécurisé, httponly)
setcookie ( "pseudo" , "JohnDoe" , time () + 3600 , "/" , "" , false , true );
// Expire dans 1 heure, accessible sur tout le site, HTTP Only pour sécurité XSS

// Accéder à un cookie
if ( isset ( $_COOKIE [ "pseudo" ])) {
    echo "Votre pseudo est : " . $_COOKIE [ "pseudo" ];
}

// Supprimer un cookie (définir une date d'expiration passée)
setcookie ( "pseudo" , "" , time () - 3600 , "/" );
?>

StockageCôté serveurCôté client (navigateur)

TailleIllimitée (par le serveur)Limitée (environ 4KB par cookie)

UtilisationAuthentification, panier d'achatPréférences utilisateur, suivi

Sécurité PHP

La sécurité est primordiale dans le développement web. Cette section aborde les menaces courantes et les meilleures pratiques pour protéger vos applications PHP.

1. Protection XSS (Cross-Site Scripting)

Le XSS consiste à injecter du JavaScript malveillant dans une page web, permettant à un attaquant de voler des informations (cookies, sessions) ou de dégrader l'expérience utilisateur. Pour s'en protéger, il est crucial d'échapper toutes les données affichées provenant de l'utilisateur.

htmlspecialchars() — Cas 1 : Affichage simple

PHP
<?php
$donnee_utilisateur = "<script>alert('XSS Attack!');</script>";

// ✅ Utilisation de htmlspecialchars pour l'affichage
echo htmlspecialchars($donnee_utilisateur, ENT_QUOTES, 'UTF-8');
// Résultat affiché : <script>alert('XSS Attack!');</script>

$commentaire = "Ceci est un commentaire avec des <b>balises HTML</b>.";
// Si vous voulez supprimer toutes les balises HTML
echo strip_tags($commentaire);
// Résultat : Ceci est un commentaire avec des balises HTML.
?>

htmlspecialchars() — Cas 2 : Pré-remplissage de formulaire

PHP
<?php
$nom_saisi = isset($_POST['nom']) ? $_POST['nom'] : '';

// ✅ Sécuriser l'affichage dans un attribut HTML
echo '<input type="text" name="nom" value="' . 
      htmlspecialchars($nom_saisi, ENT_QUOTES, 'UTF-8') . 
      '">';
?>

htmlspecialchars() — Cas 3 : Affichage dans du contenu HTML

PHP
<?php
$titre_article = $_GET['titre'] ?? 'Article sans titre';
$contenu = $_POST['message'] ?? '';

// ✅ Sécuriser les données affichées
echo '<h1>' . htmlspecialchars($titre_article, ENT_QUOTES, 'UTF-8') . '</h1>';
echo '<p>' . htmlspecialchars($contenu, ENT_QUOTES, 'UTF-8') . '</p>';
?>

2. Protection contre les Injections SQL

Les injections SQL permettent à un attaquant d'exécuter des commandes SQL arbitraires sur votre base de données, pouvant entraîner la divulgation, la modification ou la suppression de données. La solution principale est l'utilisation de requêtes préparées avec PDO (PHP Data Objects).

Requêtes préparées avec PDO — Cas 1 : Sélection de données

PHP
<?php
$dsn = 'mysql:host=localhost;dbname=ma_base;charset=utf8';
$user = 'root';
$password = 'mon_mot_de_passe';

try {
    $pdo = new PDO($dsn, $user, $password, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]);

    $id_utilisateur = $_GET['id'] ?? 1; // Donnée utilisateur

    // 1. Préparation de la requête
    $stmt = $pdo->prepare("SELECT * FROM utilisateurs WHERE id = :id");

    // 2. Exécution de la requête avec les paramètres liés
    $stmt->execute([':id' => $id_utilisateur]);

    // 3. Récupération des résultats
    $utilisateur = $stmt->fetch();

    if ($utilisateur) {
        echo "Nom: " . htmlspecialchars($utilisateur['nom']) . "<br>";
        echo "Email: " . htmlspecialchars($utilisateur['email']) . "<br>";
    } else {
        echo "Utilisateur non trouvé.";
    }

} catch (PDOException $e) {
    echo "Erreur de connexion ou de requête : " . $e->getMessage();
}
?>

Requêtes préparées avec PDO — Cas 2 : Insertion de données

PHP
<?php
// ... (initialisation PDO comme ci-dessus)

try {
    $nom = $_POST['nom'] ?? '';
    $email = $_POST['email'] ?? '';

    // 1. Préparation de la requête
    $stmt = $pdo->prepare("INSERT INTO utilisateurs (nom, email) VALUES (:nom, :email)");

    // 2. Exécution de la requête
    $stmt->execute([':nom' => $nom, ':email' => $email]);

    echo "Nouvel utilisateur ajouté avec l'ID : " . $pdo->lastInsertId();

} catch (PDOException $e) {
    echo "Erreur d'insertion : " . $e->getMessage();
}
?>

Requêtes préparées avec PDO — Cas 3 : Mise à jour de données

PHP
<?php
// ... (initialisation PDO comme ci-dessus)

try {
    $id_utilisateur = $_POST['id'] ?? 0;
    $nouvel_email = $_POST['email'] ?? '';

    // 1. Préparation de la requête
    $stmt = $pdo->prepare("UPDATE utilisateurs SET email = :email WHERE id = :id");

    // 2. Exécution de la requête
    $stmt->execute([':email' => $nouvel_email, ':id' => $id_utilisateur]);

    echo $stmt->rowCount() . " ligne(s) mise(s) à jour.";

} catch (PDOException $e) {
    echo "Erreur de mise à jour : " . $e->getMessage();
}
?>

Requêtes préparées avec PDO — Cas 4 : Récupération multiple avec fetchAll()

PHP
<?php
// ... (initialisation PDO)

try {
    $role = $_GET['role'] ?? 'user';

    // 1. Préparation
    $stmt = $pdo->prepare("SELECT * FROM utilisateurs WHERE role = :role");

    // 2. Exécution
    $stmt->execute([':role' => $role]);

    // 3. Récupération de tous les résultats
    $utilisateurs = $stmt->fetchAll();

    foreach ($utilisateurs as $user) {
        echo htmlspecialchars($user['nom']) . " - " . 
             htmlspecialchars($user['email']) . "<br>";
    }

} catch (PDOException $e) {
    echo "Erreur : " . $e->getMessage();
}
?>

3. Hashage de mots de passe

Ne JAMAIS stocker les mots de passe en clair dans la base de données. Utilisez des fonctions de hachage sécurisées pour les transformer en chaînes de caractères irréversibles. PHP offre des fonctions dédiées pour cela.

password_hash() et password_verify() — Cas 1 : Hashage lors de l'inscription

PHP
<?php
$mot_de_passe_clair = $_POST['password'] ?? 'monMotDePasseSecret';

// Hashage du mot de passe
// PASSWORD_DEFAULT utilise l'algorithme le plus fort disponible
$mot_de_passe_hashe = password_hash($mot_de_passe_clair, PASSWORD_DEFAULT);

echo "Mot de passe clair : " . htmlspecialchars($mot_de_passe_clair) . "<br>";
echo "Mot de passe haché : " . htmlspecialchars($mot_de_passe_hashe) . "<br>";

// Stocker $mot_de_passe_hashe dans la base de données
// ...
?>

password_hash() et password_verify() — Cas 2 : Vérification lors de la connexion

PHP
<?php
// Récupérer le mot de passe clair soumis par l'utilisateur
$mot_de_passe_saisi = $_POST['password'] ?? 'mauvaisMotDePasse';

// Récupérer le hash stocké en base de données
$hash_stocke_en_bd = '$2y$10$abcdefghijklmnopqrstuvwx.abcdefghijklmnopqrstuvwx.abcdefghij';

// Vérifier si le mot de passe saisi correspond au hash
if (password_verify($mot_de_passe_saisi, $hash_stocke_en_bd)) {
    echo "Connexion réussie ! Bienvenue.";
    // Démarrer la session, rediriger l'utilisateur, etc.
} else {
    echo "Mot de passe incorrect.";
}

// Re-hachage si l'algorithme par défaut a changé
if (password_needs_rehash($hash_stocke_en_bd, PASSWORD_DEFAULT)) {
    $nouveau_hash = password_hash($mot_de_passe_saisi, PASSWORD_DEFAULT);
    // Mettre à jour le hash dans la base de données
    echo "<br>Le mot de passe a été re-haché avec un algorithme plus fort.";
}
?>

password_hash() et password_verify() — Cas 3 : Utilisation avec Argon2i

PHP
<?php
$mot_de_passe = 'MonMotDePasseSecurisé123!';

// Hashage avec Argon2i (plus sécurisé que bcrypt)
$options = [
    'memory_cost' => 65536,  // 64 MB
    'time_cost'   => 4,      // 4 itérations
    'threads'     => 1       // 1 thread
];

$hash_argon2i = password_hash($mot_de_passe, PASSWORD_ARGON2I, $options);

echo "Hash Argon2i : " . htmlspecialchars($hash_argon2i) . "<br>";

// Vérification
if (password_verify($mot_de_passe, $hash_argon2i)) {
    echo "Mot de passe correct !";
}
?>

password_hash() et password_verify() — Cas 4 : Système d'authentification complet

PHP
<?php
session_start();

// Simulation d'une base de données
$utilisateurs_bd = [
    ['id' => 1, 'email' => 'alice@example.com', 
     'hash' => '$2y$10$...'], // Hash bcrypt
];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $email = $_POST['email'] ?? '';
    $password = $_POST['password'] ?? '';

    // Rechercher l'utilisateur
    $user = null;
    foreach ($utilisateurs_bd as $u) {
        if ($u['email'] === $email) {
            $user = $u;
            break;
        }
    }

    // Vérifier le mot de passe
    if ($user && password_verify($password, $user['hash'])) {
        $_SESSION['user_id'] = $user['id'];
        $_SESSION['email'] = $user['email'];
        header('Location: dashboard.php');
        exit();
    } else {
        $erreur = "Email ou mot de passe incorrect.";
    }
}
?>
💡
Bonne pratique : Utilisez toujours PASSWORD_DEFAULT avec password_hash() et password_verify(). password_needs_rehash() permet de mettre à jour les mots de passe hachés si l'algorithme par défaut ou les options ont évolué, sans forcer les utilisateurs à changer leur mot de passe.

Algorithmes de hachage

PASSWORD_DEFAULT : L'algorithme par défaut, actuellement Argon2i ou bcrypt. C'est le choix recommandé car il évolue avec les meilleures pratiques de sécurité.

PASSWORD_BCRYPT : Un algorithme robuste et largement utilisé. Il est lent par conception pour résister aux attaques par force brute.

PASSWORD_ARGON2I : L'algorithme le plus récent et le plus recommandé. Il est conçu pour être résistant aux attaques par force brute et aux attaques par dictionnaire, et il est également résistant aux attaques par GPU.

POO PHP

Principes de la POO

La Programmation Orientée Objet (POO) est un paradigme de programmation qui organise le code autour d'objets plutôt que de fonctions et de logique. Les concepts clés sont : Classe (un modèle pour créer des objets), Objet (une instance d'une classe), Propriété (une variable associée à une classe/objet), Méthode (une fonction associée à une classe/objet), Encapsulation (regrouper les données et les méthodes au sein d'une unité), Héritage (permettre à une classe d'hériter des propriétés et méthodes d'une autre classe), et Polymorphisme (la capacité d'un objet à prendre plusieurs formes).

Classes et Objets

PHP
<?php
class Voiture {
    // Propriétés
    public $marque;
    public $modele;
    private $vitesse = 0; // Encapsulation: propriété privée

    // Constructeur
    public function __construct($marque, $modele) {
        $this->marque = $marque;
        $this->modele = $modele;
        echo "Une nouvelle voiture " . $this->marque . " " . $this->modele . " a été créée.<br>";
    }

    // Méthodes
    public function accelerer($increment) {
        $this->vitesse += $increment;
        echo "La voiture accélère à " . $this->vitesse . " km/h.<br>";
    }

    public function freiner($decrement) {
        $this->vitesse -= $decrement;
        if ($this->vitesse < 0) $this->vitesse = 0;
        echo "La voiture freine à " . $this->vitesse . " km/h.<br>";
    }

    public function getVitesse() {
        return $this->vitesse;
    }

    // Destructeur (optionnel)
    public function __destruct() {
        echo "La voiture " . $this->marque . " " . $this->modele . " est détruite.<br>";
    }
}

// Création d'objets (instances de la classe Voiture)
$maVoiture = new Voiture("Toyota", "Corolla");
$saVoiture = new Voiture("Honda", "Civic");

// Accès aux propriétés et méthodes
echo "Ma voiture est une " . $maVoiture->marque . " " . $maVoiture->modele . ".<br>";
$maVoiture->accelerer(50);
$maVoiture->freiner(20);
echo "Vitesse actuelle de ma voiture : " . $maVoiture->getVitesse() . " km/h.<br>";
?>

Héritage

PHP
<?php
class Vehicule {
    protected $roues;
    protected $couleur;

    public function __construct($roues, $couleur) {
        $this->roues = $roues;
        $this->couleur = $couleur;
    }

    public function afficherInfos() {
        echo "Ce véhicule a " . $this->roues . " roues et est de couleur " . $this->couleur . ".<br>";
    }
}

class Moto extends Vehicule {
    public $typeGuidon;

    public function __construct($couleur, $typeGuidon) {
        parent::__construct(2, $couleur); // Appelle le constructeur de la classe parente
        $this->typeGuidon = $typeGuidon;
    }

    public function afficherInfos() {
        parent::afficherInfos(); // Appelle la méthode parente
        echo "C'est une moto avec un guidon de type " . $this->typeGuidon . ".<br>";
    }
}

$maMoto = new Moto("rouge", "sport");
$maMoto->afficherInfos();
?>

Interfaces et Classes Abstraites

Interface : Définit un contrat que les classes doivent respecter en implémentant toutes les méthodes déclarées. Une classe peut implémenter plusieurs interfaces.

Classe Abstraite : Une classe qui ne peut pas être instanciée directement. Elle peut contenir des méthodes abstraites (sans implémentation) et des méthodes concrètes.

PHP
<?php
// Interface
interface Forme {
    public function calculerAire(): float;
    public function calculerPerimetre(): float;
}

// Classe Abstraite
abstract class Figure implements Forme {
    protected $nom;

    public function __construct($nom) {
        $this->nom = $nom;
    }

    public function getNom(): string {
        return $this->nom;
    }

    // Méthode abstraite, doit être implémentée par les classes enfants
    abstract public function afficherDescription();
}

// Classe concrète héritant de Figure et implémentant Forme
class Cercle extends Figure {
    private $rayon;

    public function __construct($nom, $rayon) {
        parent::__construct($nom);
        $this->rayon = $rayon;
    }

    public function calculerAire(): float {
        return M_PI * $this->rayon * $this->rayon;
    }

    public function calculerPerimetre(): float {
        return 2 * M_PI * $this->rayon;
    }

    public function afficherDescription() {
        echo "Je suis un " . $this->getNom() . " avec un rayon de " . $this->rayon . ".<br>";
    }
}

$monCercle = new Cercle("Cercle", 5);
$monCercle->afficherDescription();
echo "Aire : " . $monCercle->calculerAire() . "<br>";
echo "Périmètre : " . $monCercle->calculerPerimetre() . "<br>";
?>
